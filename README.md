LINGUA – Language Translator
Project Overview

LINGUA is a Python-based Language Translator application developed using Tkinter. It allows users to translate text between multiple languages using the MyMemory Translation API.

The application also provides romanized text and pronunciation support for Chinese, Japanese, and Korean languages.

Features
Translation between 14 different languages.
User-friendly graphical interface.
Chinese Pinyin romanization.
Japanese Hepburn romanization.
Korean academic romanization.
Text swapping between selected languages.
Copy translated text.
Copy romanized text.
Clear all text fields.
Character counter.
Translation status messages.
